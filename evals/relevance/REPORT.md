## 빈 추천 8건은 모두 검색 후보 0개다

| 문항 | 질문 분해가 낸 조건 | 원인 |
| --- | --- | --- |
| R033, R037 | `genres=["Story"]` 등 | 질문 분해가 취향을 분류로 만들어 냈다. IGDB에 `Story`라는 장르·테마·키워드는 없다 |
| R040 | `genres=["Competition"]` | 같다 |
| R013 (2회차) | `genres=["Narrative", "Choice"]` | 같다 |
| R038 | `genres=["Fantasy", "Action", "Role-playing (RPG)"]` | **검색의 버그.** 아래 |

- **같은 배열에 이름 조건을 둘 걸면 0건이다.** `Fantasy`와 `Action`은 둘 다 IGDB의 테마다.
  `themes.name ~ "fantasy" & themes.name ~ "action"`을 IGDB는 "한 원소가 두 이름을 동시에 만족"으로
  읽는다. `Fantasy + RPG`(테마 + 장르)는 되고 `Fantasy + Action`(테마 + 테마)은 0건이다. id로
  `themes = [17,1]`이라고 쓰면 된다(확인함). 장르 둘(`Puzzle + Arcade`)도 같은 이유로 0건일 것이다.
  검색 정렬을 바꾸기 전부터 있던 문제다.
- **지어낸 분류는 키워드 부분 일치로 살릴 수 있다.** `keywords.name ~ "story"`는 0건이지만
  `keywords.name ~ *"story"*`는 Skyrim, God of War, Mass Effect 2 등을 돌려준다(확인함).
  `*"competiti"*`도 Counter-Strike, Overwatch, StarCraft II를 돌려준다.

둘 다 고쳤다(2026-09-20, `evals/search_pool/REPORT.md`의 같은 날짜 절). 분류·게임 모드는 id로 걸고,
지어낸 분류는 키워드 이름을 조회해 단어의 시작이 맞는 것만 id로 건다. 빈손이던 네 문항이 후보 30개를
받는다. 이 평가의 비교(같은 후보 풀의 두 목록)에는 영향을 주지 않는다. 비교할 문항 수만 줄었다.

## 읽을 때 주의

- 심판은 사람이 공인한 정답이 아니다. 자리 편향이 크다는 것이 확인된 모델이고, 두 번 물어 합치는
  규칙으로 걸렀을 뿐이다.

  33~43%이고, 나머지는 비기거나 같은 목록이다.
- 심판은 질문에 맞는 정도만 본다. 같은 게임이 여러 질문에 반복해서 나오는 문제는 이 평가에 잡히지
  않는다.
- 문항은 사양·평점·무료 강제·제외 표현을 뺀 것이다. 그런 질문에서의 선택은 재지 않았다.

### 측정 조건

- **Steam 요청 제한.** 1회차를 10/05처럼 동시성 2로 돌렸더니 마지막 다섯 문항(R036~R040)에서 Steam
  appdetails가 429를 냈다. 수정 뒤에는 Steam id가 있는 후보가 늘어, 같은 실행이 Steam을 더 많이 부른다. 두
  문항은 오류로 끝났고 세 문항은 가격·사양 단계가 실패했다.
  이 다섯 문항을 다시 돌려 1회차 합계에 넣었다. 결과가 아니라 오류가 난 구간으로 골랐고, 1회차 원 기록은
  그대로 두었다(원 기록 그대로 세면 승 8, 패 1, 비김 26, 같은 목록 3, 오류 2).
- 재실행과 2회차는 평가 프로세스의 HTTP 전송을 감싸 요청을 조절했다. 앱 코드는 그대로다. appdetails는 5분에
  150회 이하, 요청 사이 0.25초 이상이고, 한 문항 분량이 5분 창에 남을 때까지 문항 사이에서 기다렸다. 같은
  GET은 실행 동안 한 번만 보냈고, 429를 받으면 Retry-After 동안 보내지 않았다. 동시성은 1이다. 두 실행 모두
  appdetails는 429 없이 200만 받았다(2회차 214번).
- **CheapShark**(Steam 밖 게임 가격)는 측정 내내 429였다(Retry-After 약 37분). 그동안 요청을 보내지 않아 Steam
  밖 게임의 가격은 확인 불가였다. 예산 문항에서 그런 게임은 양쪽 목록 모두에서 빠진다. 10/05에도 CheapShark
  실패가 많았다.
- **Steam 리뷰**(appreviews)는 모든 요청이 302로 스토어 첫 화면으로 넘어가 리뷰 요약이 전부 실패했다. 심판은
  리뷰를 보지 않고, 리뷰 요약은 목록이 정해진 뒤에 붙는다.
- 10/05에는 Steam 할인으로 RDR2·God of War·Witcher 3가 예산 문항(R030·R032·R035·R039)의 목록에 들었지만, 이번에는
  한 번도 들지 않았다. 예산 문항의 목록은 10/05와 직접 견주지 않는다.
- **비용.** 2회차를 응답의 토큰 수로 계량해 $0.297였다(gpt-4o-mini 호출 366번, 입력 약 296만 토큰 중 73%가
  캐시, 출력 약 2.5만 토큰). 리뷰 요약이 실패해 그 비용은 빠졌다. 재실행 5문항은 $0.035이고, 1회차(계량하지
